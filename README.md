# Проект API Yatube

## Описание
REST API для социальной сети Yatube. Проект позволяет публиковать записи (посты), оставлять к ним комментарии и подписываться на других авторов. Доступ к API реализован с использованием JWT-токенов. Аутентифицированные пользователи могут изменять и удалять свой контент, а для анонимных пользователей доступно только чтение.

## Установка
1. Создайте и активируйте виртуальное окружение:
   `python -m venv venv`
   `.\venv\Scripts\activate` (для Windows)
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Выполните миграции:
   `cd yatube_api`
   `python manage.py migrate`
4. Запустите локальный сервер:
   `python manage.py runserver`

## Примеры запросов
- **Получение JWT-токена**: `POST /api/v1/jwt/create/` (передать `username` и `password`)
- **Получение списка постов**: `GET /api/v1/posts/`
- **Создание подписки**: `POST /api/v1/follow/` (доступно только авторизованным пользователям)
